# Inspiration workflow

1. Search by outcome, not by brand: `animated hero`, `saas onboarding`, `editorial portfolio`, `3d product card`.
2. Inspect hierarchy, typography, grid, surface treatment, motion, states, responsive behavior, accessibility, and performance.
3. Convert observations into explicit design requirements.
4. Search registered component sources for an implementation that satisfies those requirements.
5. Install the smallest exact component or package.
6. Re-test the final implementation in the target browser.
