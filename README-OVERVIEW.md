# ui overview

Intent-driven UI skill resolver and installer for coding agents.

The project distinguishes foundation skills, conditional skills, component registries, runtime packages, and inspiration/reference sources.

Foundation skills: Impeccable and design-taste-frontend (Taste).

Specialist skills are selected from project intent and framework. Third-party component libraries are not bulk-downloaded; the resolver searches by capability and outcome, then installs the smallest exact component through the official registry or package mechanism.

Inspiration searches use outcomes such as animated hero, SaaS onboarding, 3D product card, editorial portfolio, or dashboard command palette. The workflow extracts hierarchy, grid, typography, surfaces, interaction states, motion, responsive behavior, accessibility, and performance rather than copying a site verbatim.
